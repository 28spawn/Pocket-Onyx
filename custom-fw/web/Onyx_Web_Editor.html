Amp captures

USB only (a capture is 7.5 KB: Bluetooth is too slow for it). A ToneHunt .nam is read here: the JSON is stripped and its A2 Lite model (1870 weights) is packed into the unit's 7,504-byte capture, named from the file's metadata. A .namb container is cut to its model struct (3852 B), a raw struct or a WAVE blob is sent as it is. Up to 8192 B. The unit keeps up to 10 captures; delete or replace one to make room. Presets name a capture by its number, so deleting one leaves a gap instead of renumbering the others.

Cabinets

A WAV impulse response (16/24/32-bit PCM or float, any sample rate) is resampled to 44.1 kHz, trimmed and cut to 1024 taps in the browser; a raw file is the unit's own format (Q18 taps, int32 little-endian, 16 to 1024). The unit keeps up to 15 cabinets in the flash. "Try live" loads one into the cabinet block without storing it (gone at the next cabinet change or power-off).

Save and restore presets

All 80 presets as one .json file: save a backup from the unit, edit it in a text editor if you like, and write it back. A restore keeps every preset exactly as it was saved (its save counter and EMPTY slots too) and checks it by reading it back. The restored preset is used the next time you select its slot. Needs firmware 1.08 or newer.

Import a bank file

A .json backup, or an .abkx bank exported from the stock app (80 records of 92 bytes). An .abkx is converted here in the browser; the file is only read and never uploaded anywhere. Its stock effects are mapped onto the Onyx slots (see MIDI-MAP-CUSTOM.md); that file has no preset names, so they are called P01...P80.

⚠ Back up your unit's critical flash regions before you install any different firmware

An update or a flash tool can erase what nothing can make again: the stock record log with the radio calibration (without it Bluetooth does not start; one run of a flash tool erased it once), the Bluetooth MAC and RF calibration (BTIF), the factory calibration (USER), key_mac, and the boot head. The backup is about 60 KB, takes under a minute with the amp idle, and is saved to your computer.

Firmware update

Over USB MIDI, in one click, the way the Pendel installer does it: the running firmware checks the package and stages its update loader, the loader writes the firmware and the unit restarts. Chrome or Edge (Web MIDI with SysEx), the unit connected directly by a USB data cable, no other program using it. Do not unplug while it works; if it is cut off the unit stays in update mode and the same button continues.

Install a firmware

pick the Pocket_AMP_Custom.fwsc the build writes
works from the original firmware and from this one. It rewrites the app area and the area behind it: your stored captures and cabinets are erased (the PC tool below keeps them). The Onyx update loader (an install of an Onyx package) writes the app area only.
